# パイプライン最適化 計測・検証結果報告書 (04-results.md)

本報告書は、`ROADMAP.md` §16 に掲げられた 3 大最適化テーマ（M1: PTY 送信のベクタード I/O 化、M2: 純粋 Rust JPEG エンコーダの AVX2/NEON SIMD ベクトル化、M3: エンコード・PTY 送信の完全非同期パイプライン化）の実装完了に伴うベンチマーク計測値と検証結果を記録するものです。

## 1. 総合パフォーマンス計測結果

### 1.1 JPEG 1080p (1920x1080) フルフレーム・エンコード速度 (Release ビルド)

CPU: x86_64 (AVX2 対応環境), 品質: 75, 解像度: 1920x1080 (約 2.07 MP)

| 実装バックエンド | エンコード所要時間 | フレームサイズ | 速度比 (Speedup) |
| :--- | :--- | :--- | :--- |
| **Scalar（改修前・基準）** | **13.07 ms** | 102 KB | 1.00x (基準) |
| **AVX2 SIMD（改修後）** | **3.98 ms** | 102 KB | **3.29x 高速化** |

> [!NOTE]
> M2 の完了目標値（2.0x 以上）を大幅に上回り、**3.29倍（所要時間 1/3.3）** を達成しました。
> 色変換（MCU 単位の単一メモリアクセス融合）・2D 8x8 FDCT（AVX2 転置並列化）・量子化（64bit 並列乗算）の各段で完全にスカラー演算を置換しています。

### 1.2 パイプライン並行度（ダブルバッファリング効果）

Encode 10ms + Write 10ms の人工遅延下での 30 フレーム連続処理時間（PIP-004）:

| 処理方式 | 理論直列時間 ($T_{enc} + T_{write}$) | 実測総処理時間 | 並行効率 |
| :--- | :--- | :--- | :--- |
| **直列処理 (M1 相当 / `TERMWAY_PIPELINE=serial`)** | 約 600 ms + 送信待機 | 約 900 ms | 直列ブロッキング |
| **Double-Buffering パイプライン (M3)** | 約 300 ms ($\max(T_{enc}, T_{write})$) | **約 330 ms** | **理論限界に近い並行性達成** |

## 3. 結論

1. **PTY 送信ゼロコピー化 (M1)**: `libc::writev` による scatter-gather 出力により、256KB の中間バッファ `memcpy` を全廃。
2. **SIMD JPEG 高速化 (M2)**: 1080p フルフレームエンコードが 13.07ms から **3.98ms** へ 3.29 倍高速化。INV-4（ビット完全一致）を保証。
3. **Double-Buffering パイプライン化 (M3)**: Encode スレッドと Write スレッドを 2 面ピンポンバッファで分離し、直列合算レイテンシを解消。
4. **安全弁**: `TERMWAY_JPEG_SIMD=0` / `TERMWAY_PIPELINE=serial` により、いつでも旧挙動への無停止フォールバックが可能。
